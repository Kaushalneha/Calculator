# Project Overview

This project is a lightweight utility app designed to perform basic arithmetic operations with a focus on a polished user interface and robust input logic. It is built to be responsive, ensuring a consistent look across different Android screen sizes.

# Tech Stack

1. Language: Java

2. UI Design: XML (Material Design 3)

3. Minimum Android Version: Android 7.0 (API 24)

4. Development Tool: Android Studio


 # Key Features

1. Modern UI: High-contrast Dark Mode with rounded Material buttons.


2. Essential Math: Supports Addition, Subtraction, Multiplication, and Division.


3. Smart Logic:
Prevents multiple decimal points in a single number.


4. Handles division by zero without crashing.


5. Responsive Layout: Uses a GridLayout system that adapts to any screen size.


6. Instant Clear: A dedicated "C" button to reset all calculations.
